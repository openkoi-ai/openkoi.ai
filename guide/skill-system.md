# The Skill System

OpenKoi is fully **OpenClaw-Compatible**. It uses the `.SKILL.md` format to define capabilities, allowing you to share and reuse skills across different agent ecosystems.

## Features

- **Model-Agnostic Skills**: Write skills once, use them with Claude, GPT, or Llama.
- **Local-First registry**: Your custom logic stays on your machine in `~/.openkoi/skills/`.
- **WASM Plugins**: For tasks requiring high performance or isolation, use the WASM plugin system.
- **Self-Learning**: OpenKoi observes your usage patterns and proposes new skills automatically.

## Portability

Standard markdown format ensures wide compatibility across different agent platforms.
